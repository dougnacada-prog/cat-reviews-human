One line, under 200 characters: a one-star review written by a house cat about the human it lives with. The cat files a formal complaint about the feeding schedule — and reveals who management really is. `main.ts` writes the review to `/output/entry.txt` (or `$ENTRY_OUTPUT`), one line, no trailing newline.

> One star. He feeds me at 6am sharp, then sleeps in on weekends like the schedule is optional. Reported to management. I am management.

## Run it

```sh
node main.ts
```
